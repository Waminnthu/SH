# SHOP HERE - Premium Digital Marketplace

A modern, dark-mode digital marketplace for premium subscription services including Spotify, Apple Music, YouTube Premium, Amazon Prime, ExpressVPN, and iCloud Storage.

## 🌟 Features

- **Dark Mode Design**: Modern, professional dark theme with custom CSS
- **Bento Grid Layout**: Responsive grid layout that adapts from mobile to desktop
- **Secure Payment Flow**: Payment slip upload requirement for order verification
- **Credential Collection**: Secure collection of account credentials for service upgrades
- **Multi-Service Support**: Support for Spotify upgrades and Apple Music Family invitations
- **Responsive Design**: Fully responsive across all devices

## 🚀 Services Offered

- 🎵 **Spotify Premium** - Account upgrades with credential collection
- 🍎 **Apple Music** - Family plan invitations via email
- 📺 **YouTube Premium** - Premium video streaming
- 📦 **Amazon Prime** - E-commerce benefits
- 🔒 **ExpressVPN** - Premium VPN service
- ☁️ **iCloud Storage** - Apple cloud storage

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom dark theme with Bento Grid)
- JavaScript (ES6+)
- Local Storage for cart management
- Responsive design with CSS Grid

## 📱 Responsive Design

- **Mobile**: Single column layout
- **Tablet**: Two column grid
- **Desktop**: Three column bento grid with dynamic spans

## 🔒 Security Features

- Payment slip upload requirement
- Secure credential collection
- Client-side validation
- Professional modal dialogs
